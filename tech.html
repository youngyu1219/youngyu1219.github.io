How This Site Is Built

技术说明

这个博客没有用重型框架，而是用最朴素的三件套——HTML、CSS、JavaScript，把国风的审美一点点搭出来。

技

用到的技术

Tech Stack
结
STRUCTURE

HTML5 语义化结构

用 header / nav / main / section / article 组织页面，让结构清晰、便于维护与无障碍阅读。

式
STYLE

CSS3 设计系统

以 CSS 变量统一配色与字体，Grid / Flex 布局，渐变、阴影与关键帧动画构成整套国风视觉。

动
INTERACTION

原生 JavaScript

IntersectionObserver 做滚动揭示，手写轮播与移动端抽屉，不依赖任何第三方库。

韵
AESTHETIC

国风字体与配色

朱砂红、墨色、宣纸米白与金赭构成主色；标题用宋体衬线，正文用无衬线，兼顾韵味与可读性。

适
RESPONSIVE

响应式布局

媒体查询适配桌面与手机，移动端导航收纳为抽屉，栅格自动降列，保证小屏也干净。

布
DEPLOY

静态部署

纯静态站点，可直接托管在 GitHub Pages、对象存储或任意 Web 服务器，无后端、无数据库。

序

站点是怎么搭起来的

Workflow
01

结构

先定页面骨架：首页、文章、项目、关于、归档、404，规划统一的导航与页脚。

02

样式

建立设计变量与复用组件（封面、卡片、按钮、印章、云纹），再逐页填充内容。

03

交互

加入滚动揭示、轮播与滚动标语，让页面有节奏，但不过度打扰阅读。

04

部署

静态文件直接托管上线，后续用 Git 管理版本，改一篇、推一次即可。

码

关键代码片段

Snippets

① 用 CSS 变量统一国风配色：

/* 国风设计变量 */
:root {
  --ink:      #221e18;  /* 墨 */
  --paper:    #f6f1e6;  /* 宣纸米白 */
  --cinnabar: #b23a2e;  /* 朱砂红 */
  --jade:     #2f6b5e;  /* 青绿 */
  --gold:     #b8934e;  /* 金赭 */
}

② 滚动到视口时才播放入场动画：

// 滚动揭示
const io = new IntersectionObserver((entries) => {
  entries.forEach((e) => {
    if (e.isIntersecting) {
      e.target.classList.add('in');
      io.unobserve(e.target);
    }
  });
}, { threshold: 0.12 });

document.querySelectorAll('.reveal')
  .forEach((el) => io.observe(el));
构

目录结构

Structure 
blog-tang/
├── index.html        # 首页
├── about.html        # 关于我
├── projects.html     # 项目
├── archives.html     # 文章 / 归档
├── tech.html         # 技术说明
├── 404.html          # 404 页
├── css/
│   └── style.css     # 设计系统
├── js/
│   └── main.js       # 交互脚本
├── img/              # 配图
└── posts/            # 文章页

整个站点没有构建步骤，也没有依赖包。克隆下来、双击 index.html 就能在浏览器打开。

要发布时，把整个文件夹上传到 GitHub Pages 或任意静态托管即可。改一篇文章，只需要在 posts/ 下新增一个 HTML 文件。
